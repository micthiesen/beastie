## Native checks

The final archive was extracted into a new directory. Its extracted `usr/bin` tree passed
`packaging/linux/validate-layout.sh`, and the extracted package manifest retained the SHA-256 above.
The included `README-LINUX.txt` identifies the x86-64 desktop baseline and `./AppRun` launch command.

The VM network interface was set `DOWN`; a bounded `curl` failed DNS resolution before testing.
With `BEASTIE_DISABLE_NETWORK=1`, a clean XDG profile, Mesa software rendering, Xvfb, and a local
ALSA null device for the headless guest:

1. `./AppRun --smoke` rendered and exited zero.
2. The eight-step `aquarium-v1-visible.jsonl` scenario completed from the extracted archive.
3. The typed line `Do you remember the berry?` produced the local Qwen reply `hm. rude giant.`.
4. Packaged eSpeak produced a valid 70,094-byte cached WAV under
   `$XDG_CONFIG_HOME/beastie/tts-cache`, outside the extracted bundle.
5. A separate clean profile created `$XDG_CONFIG_HOME/beastie/saves/main.json`, quit through the
   native window path, reloaded that save, and quit zero again. The save and backup remained outside
   the install tree.
6. After every exit, no `beastie`, `beastie-ai-worker`, `llama-server`, `beastie-tts`, or
   `beastie-stt` process remained.

The final offline captures are retained locally under
`target/release-evidence/linux/typed-scenario/` alongside the bundle.

## Honest limits

OrbStack exposes no physical microphone or real audio output device. This run proves packaged model
loading, recognition, synthesis, cache placement, graphics launch, typed local dialogue, saves, and
process cleanup. It does not prove Linux microphone permission behavior, live endpointing feel, or
audible output quality. The first minimal guest launch also confirmed that a server-only Ubuntu
image lacks `libxkbcommon-x11-0`; Ubuntu Desktop includes it, and the bundled README lists the
minimal-host dependency explicitly.
